# Design Rationale

## Direction

The site uses a dark, precise visual system that combines editorial spacing with technical instrumentation cues. It is meant to feel closer to a lab notebook or systems console than a startup landing page.

- Primary palette: graphite, slate, cyan, and muted teal
- Display type: `Space Grotesk`
- Technical labels: `IBM Plex Mono`
- Surface treatment: glass panels, thin borders, and a subtle grid overlay

## Why It Fits The Narrative

- Robotics and simulation work benefit from a layout that suggests structure, signals, and constraints.
- The restrained palette keeps attention on the content while still feeling distinct.
- The typography split between display, body, and mono labels helps the site read as both designed and engineered.

## Visual Rules

- Keep one primary accent color.
- Use thin borders and grid overlays to imply structure.
- Let spacing and hierarchy create confidence instead of relying on loud gradients or gimmicks.
- Use motion only to reinforce focus and navigation.

## Component Rules

- Every section should have a clear label, headline, and support copy.
- Cards should present a thesis, then evidence.
- Tags describe technical domains and stacks, not shallow proficiency ratings.
- Leadership content should look like system responsibility, not self-promotion.
