# Content Strategy

## Positioning Statement

JJ / EXIBIST is an engineer and student building robotics, AI, simulation, and systems software with a strong bias toward architecture, operator workflow, and real-world deployment constraints.

## Visitor Story

1. The homepage establishes identity, technical range, and leadership credibility quickly.
2. The visitor sees that the work is broader than isolated class projects.
3. Featured projects show range across robotics, ML, simulation, vision, and systems design.
4. The leadership page grounds the portfolio in real team responsibility and collaborative engineering.
5. The projects page provides enough depth to validate seriousness without overwhelming the reader.

## Section Hierarchy

- Home
  - hero
  - focus domains
  - featured work
  - FRC leadership block
  - engineering philosophy
  - contact
- About
  - identity
  - working style
  - technical focus
  - principles
- Projects
  - featured projects
  - full project index
  - placeholder slots for future public artifacts
- Leadership
  - ASL Robotics / FRC Team 1884 context
  - repository and tooling responsibility
  - collaboration and systems pressure

## Copy Rules

- Favor technical clarity over marketing language.
- Describe why work matters, not just what stack was used.
- Frame FRC work as leadership and systems contribution, not sole ownership of every repo.
- Use placeholders only when explicitly marked.

## Project Grouping Strategy

- Robotics systems
- AI and machine learning
- Simulation and tooling
- Interfaces and technical product surfaces
- Graphics or engine experiments
